## 2. 운영 환경

현재는 `local`과 `https-test` 프로필만 있다. https-test는 가입·소셜 로그인을 막고 만료·R2 정리를 dry-run으로 고정하므로 그대로 운영에 쓸 수 없다.

- [ ] 운영 프로필 추가 (예: `prod`). https-test의 안전 가드(TLS 검증 DB, 강한 JWT, actuator health만 노출, 상세 오류 숨김, `ddl-auto: validate`)는 유지하고, 가입·소셜 로그인 허용과 만료·정리 설정만 운영값으로 바꾼다.
- [ ] 운영 프로필 시작 검사: 테스트 버킷·테스트 DB·개발용 JWT 기본값을 가리키면 기동 거절
- [ ] **(결정)** 호스팅. Render Free는 15분 동안 요청이 없으면 잠들고, 다음 접속 때 수십 초~수분 기동한다. 하객이 카톡 링크를 눌렀을 때 하얀 화면이 그만큼 오래 가면 실사용이 어렵다. 출시 기간만 유료 인스턴스를 쓰는 등 비용을 확인한 뒤 정한다.
- [ ] 운영 DB: 새 Neon 프로젝트(또는 결정한 DB). 테스트 DB를 재사용하지 않는다. Flyway V1부터 새로 적용
- [ ] 운영 DB 백업과 복구 방법 확인 (무료 플랜 복구 보관 기간 확인)
- [ ] 운영 R2 버킷과 그 버킷만 쓸 수 있는 키. CORS에 운영 Origin의 PUT/GET/HEAD 허용, 공개 주소(`public-base-url`) 확정
- [ ] 도메인 구매·연결과 HTTPS 확인. 서브도메인 슬러그를 쓸 거면 와일드카드 DNS·인증서 지원 여부도 확인
- [ ] `APP_PUBLIC_ORIGIN`, `invi.frontend.base-url`을 운영 Origin으로 설정
- [ ] 테스트 R2 토큰 `invi-https-test-upload`가 **2026-11-28 만료**된다. 테스트 환경을 계속 쓸 거면 교체하고, 아니면 정리한다.
